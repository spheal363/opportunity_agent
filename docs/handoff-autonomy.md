## 残っている制約・別件

- 自動探索は既定オフ。起動条件と設定方法は README と api.md を参照。
- 費用の条件は記録済みの LLM 見積もり額で次の自動 run を止めるもの。
  実行中の run を中断する予算上限はなく、検索・取得・Jev を含む請求総額の保証でもない。
  自動開始の排他は 1 worker 前提。
- 既存 main 由来: 👎→👍でも候補自体の status=dismissed は戻らないため、
  本番探索ではその候補は除外され続ける。今回直した自動開始判定とは別の状態遷移の問題。
- 既存 main 由来: stub 探索は dismissed 候補も再推薦するため、実探索と挙動が異なる。
- 結果取得の所有者チェック欠落はレビュー後に修正済み（冒頭参照）。
