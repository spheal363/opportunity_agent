## 4. この経路の位置づけ

**「正常に動く基準」はできた。**

- `finish_reason` で成否を機械的に判定できる（5/5 が `stop`）
- 実費が応答に直接乗り、settled と一致する
- 生レスポンス・引用・usage・request ID をすべて保存できている

**まだ言えないこと**: 発見の幅。1 リクエストで 9 件、日程ありは 6 件で、
ハッカソンと DTM は 0 件。**Responses API や既存方式との優劣は、
この基準の上で条件を揃えてから比較する。**
